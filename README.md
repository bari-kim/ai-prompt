A personal AI image prompt archive built with Next.js, SQLite, Drizzle ORM, and Cloudflare R2.

## Setup

1. Copy frontend/.env.example to frontend/.env.local.
2. Set ADMIN_PASSWORD_HASH using npm run generate-admin-password.
3. Run npm install.
4. Start the app with npm run dev.

The local database is created automatically at frontend/data/prompt-archive.sqlite. No cloud database, account, or payment method is required for local use.

## Admin authentication

This is a single-admin application. There is no signup, user account, or administrator email.

    npm run generate-admin-password

Copy the generated Argon2id hash into frontend/.env.local:

    ADMIN_PASSWORD_HASH="\$argon2id\$v=19\$..."
    SESSION_SECRET="use-a-long-random-value"

    npm run generate-admin-password

Copy the generated Argon2id hash into frontend/.env.local:

    ADMIN_PASSWORD_HASH="\$argon2id\$v=19\$..."
    SESSION_SECRET="use-a-long-random-value"

. Next.js expands unescaped dollar signs in environment files and would corrupt the password hash. Restart the server after changing `.env.local`.

The plaintext password is never saved by the generator. Every admin page and mutation verifies the server-side session.

## SQLite backups

Create a timestamped backup copy:

    npm run db:backup

Backups are stored in frontend/data/backups/. Add that directory to an external backup routine or copy it to another drive/cloud storage.

The SQLite file is local and should not be committed. When R2 is configured, the R2 bucket stores uploaded images. Without R2 configuration, images are saved in an uploads directory beside the SQLite database (frontend/data/uploads by default). Back up this uploads directory along with the database. Local images retain the prompt’s public/private access rules; the SQLite database stores prompt metadata, tags, counters, and sessions.

## Environment variables

See frontend/.env.example:

- SQLITE_DB_PATH: optional database path, relative to frontend
- ADMIN_PASSWORD_HASH: Argon2id hash generated by the password command
- SESSION_SECRET: session-related secret configuration
- R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, R2_BUCKET_NAME: private R2 configuration
- NEXT_PUBLIC_SITE_URL: public site URL
